# Ember & Oak concept

Work only in this repository for the restaurant demo. Preserve the warm charcoal, cream and terracotta identity. This is a fictional restaurant, not a client launch.

Keep menu examples illustrative, reservation controls preview-only, and all image-generation provenance in docs. Never add real contact actions, fabricated testimonials, booking submission, analytics or indexable metadata without a new request.

Keep content usable without animation; respect reduced motion. On mobile, the signature sequence is vertical with no sticky or pinned scrolling. Use ordinary in-page anchors.

Check TypeScript, browser interactions and the production build before completion. Publishing and linking from Krelyvo are separate milestones. Do not create a .lovable folder.
